Network Intrusion Detection System

Illustrative prediction only. This demo scores traffic with simple heuristics; a trained UNSW-NB15 model would use the full feature set.

Project at a glance

Classify network traffic as Normal or Malicious using UNSW-NB15 (about 2.54 million records; alternative: CIC-IDS2017). Focus on attack-class recall and false negatives, and drop identifiers or label-derived columns.

Project workflow

  1. Load and understand the dataset
  2. Exploratory data analysis
  3. Prepare data (features, encoding, scaling, no leakage)
  4. Split 80/20 with stratification
  5. Train Logistic Regression, Decision Tree, Random Forest
  6. Evaluate: accuracy, precision, recall, F1, confusion matrix
  7. 5-fold cross-validation
  8. Hyperparameter tuning with GridSearchCV
  9. Select the best model; evaluate once on the test set
  10. Predict new, unseen data
  11. Save model and pipeline with joblib; build the interface
